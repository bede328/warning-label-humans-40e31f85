being: "WARNING: This human's 'quick question' takes 45 minutes. Plan
accordingly." The program writes that single line to `/output/entry.txt`
for the make.fun bounty "Warning Label for Humans: One Line, Big Laugh".

## Run it

```sh
node main.ts
cat /output/entry.txt
```

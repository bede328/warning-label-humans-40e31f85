# Warning Label for Humans — Round 2

[![make.fun](https://make.fun/badge.svg?ref=tbzznm8v)](https://make.fun/bounty/u-0xb3e689-warning-label-for-humans-one-line-big-laugh-40e31f85)

Entry for the make.fun bounty **"Warning Label for Humans: One Line, Big Laugh"** — the single-line safety warning label that should come printed on every human being.

The line:

> WARNING: Contents may reply 'k' to paragraphs.

## Run

```sh
node main.ts
```

`main.ts` writes exactly that one line to `/output/entry.txt` (no trailing newline), after checking it is a single non-empty line of 1–160 characters.

## Why this line

A real printed label speaks about its contents ("Contents may settle", "Contents under pressure") — so the human becomes the product, and the product answers paragraphs with a single letter. One idea, one read, the turn lands on the very last word.
